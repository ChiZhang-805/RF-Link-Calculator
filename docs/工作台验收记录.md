# 应用 1.1.0 工作台验收

日期：2026-09-23。默认入口已切换为固定视口工作台；schema、公式仍为 1.0.0。这里的应用版本号不代表需求计划中后续 AM/AM、S 参数等功能已实现。

## 已实现

- 链路 / 分析 / 框图切屏；顶栏常用操作、横向条件栏、底部六项结果固定。
- 右侧参数每行左标题、右控件；参数 / 频率 / 来源页签；内部滚轮滚动，隐藏滚动条，不带动页面。
- 器件表编辑、选择联动、添加 / 复制 / 删除 / 上移 / 下移、50步撤销重做、按实际视口容量分页。
- 压缩扫描、双音谱图、逐级指标分类、全部指标、错误定位、来源及混频条件编辑。
- 新建 / 打开 / 保存、JSON与规范CSV导入、六种导出入口、工程包落盘、严格检查、目录设置、按需环境诊断。
- 无常驻VSDX状态、构造示例说明、上传大小、框架Deploy/Profile或长篇模型说明。模型、来源和未知状态仍保存在数据、指标详情与导出中。
- 共享射频符号：放大器外部标注、滤波器波形及阻带、混频器LO支路、黑白符号本体；页面、SVG、draw.io同步，依据见[射频符号约定](射频符号约定.md)。
