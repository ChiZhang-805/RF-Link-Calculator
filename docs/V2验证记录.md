# V2 验证记录

此页保留 2.0.1 验收过程。当前自动化测试 XML、独立安装记录与版本为 2.1.0；新增结果见 [谐波与镜像实现验证](谐波与镜像实现验证.md)。

日期：2026-09-23。应用 2.0.1，Windows、Python 3.13.0、NumPy 2.5.3、SciPy 1.18.1、scikit-rf 2.1.0。新增厂商、公开商用算例及实测 IQ 的结果见 [公开数据验证记录](公开数据验证记录.md)。

## 已执行

- 自动化回归 **103 项通过**，其中原有 65 项、高级模型及接口 38 项。完整机器记录见 `自动化测试.xml`。运行 `python -m pytest -q --junitxml=docs/自动化测试.xml`，耗时 21.38 秒。
- Ruff 检查与格式检查通过，两个前端脚本的 Node 语法检查通过；`pip check` 无依赖冲突。
- 独立级联网络与 scikit-rf 对比、热无源 `kT(I−SSᴴ)` 与噪声系数解析对照、完整噪声参数的源失配公式、Touchstone RI/MA/DB 与 v1/v2 的 Rn 单位差异均有回归覆盖。
- 三阶多项式双音的 IM3 与独立解析值对照；高侧 LO 的不等功率载波翻转、级间本地 RF/IF 查表、固定驱动 IMT 谱线及后级路径检查通过。
- 功率曲线增益、相位、P1、有效范围、逐级实际功率传播通过；超范围不会保留旧标量压缩结果。同级完整非线性曲线与频率增益模型重复绑定时拒绝非线性计算。
- 已知复系数记忆模型拟合和隔离留出验证通过；秩不足、采样率不符、超训练峰值会拒绝；已知邻道功率比例与 FFT 功率归一化有独立数值检查。
- 对标检查覆盖缺失/重复行、单位和状态冲突、输入过期、相位 360° 等价、误差汇总及内部来源隔离。合成数据只能得到“内部自检”，不会自动成为外部精度认证。
- 五套合成工程可保存、重新导入和生成工程包。`scripts/generate_model_samples.py` 生成五套输入、九组分析结果及十个对标包（其中一个为标量 MATLAB 交接包）；`scripts/rf_lab.py` 已实际从文件重跑 201 点扫频。
- 构建 2.0.1 wheel，并安装到独立新虚拟环境、脱离源码目录运行。检查包内网页/两版 schema、HTTP 引导、旧入口、模型计算、导出、IQ 预测和两个公开参考算例。版本及实际安装路径见 `独立安装验证.json`。
