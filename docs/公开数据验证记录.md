## 实测 IQ 验证方法

固定 OpenDPD 提交 `aba888b87199d7ae7802ce931987e3aa3c951410`，采样率 800 MHz，主信道带宽 200 MHz。保留作者的训练/验证/测试划分，分别 **23040 / 7680 / 7680** 点，没有拼接后随机打散。

预先指定 20 种组合：阶数 1、3、5、7、9，记忆深度 1、3、5、8，正则系数 10⁻⁸。仅根据验证集选择，未用测试输出训练或选择模型。选中九阶、八抽头，验证 NMSE −30.6746 dB；所有候选的验证与最终测试统一跳过前 7 个启动样本。

测试集单抽头线性基线 NMSE −19.8057 dB，所选模型改善 **10.9785 dB**。测试波形预测 RMS 误差 2.8893%，消除一个最优复增益后为 2.8625%。未预先约定产品验收阈值，因此报告状态为“已评估”，不自动判定满足全部工程指标。

Hann 窗，主/左/右各 200 MHz 积分带、邻道中心偏移 ±200 MHz：实测左/右 ACPR 约 −34.0350/−32.0835 dBc，预测 −34.4547/−32.3806 dBc，误差分别 −0.4197/−0.2971 dB。这是本次指定积分口径，不声称复现 OpenDPD 论文的全部指标协议。

数据没有本次可确认的 √mW 标定，因此不报告绝对 dBm 或物理增益。独立模型标记 `amplitude_unit=normalized`，软件拒绝把它直接接入以 dBm 计算的链路。拟合内核新增独立验证记录支持；原界面的单文件隔离留出流程保持兼容。

## 工程与复现

`outputs/public-validation/projects` 含 39 个工程：36 个厂商条件工程（每条件各一个 S 参数、一个频率预算）、1 个失配级联、2 个公开算例。软件项目菜单也增加两个公开算例，未增加介绍段落。

厂商 S 文件没有完整噪声参数，S 参数工程的 NF 保持未知。频率预算使用厂商增益、NF、OIP3、输出 P1 表：`IIP3=OIP3−G`，`IP1=OP1−G+1`。这是匹配标量预算；P1 锚点不等于真实 AM/AM–AM/PM 曲线。PGA-103+ 部分低频条件不是无条件稳定，本次检查不是电路稳定性认证。

仅有增益、没有相位的模型不再把内部零相位假设显示或导出为已知相位；相位和复数 S21 标记未知。已有完整相位或 S 参数的线性链路保留对应结果。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-validation.txt
.\.venv\Scripts\python.exe scripts/fetch_public_validation.py
.\.venv\Scripts\python.exe scripts/verify_public_validation.py
```

原始文件在 `artifacts/public-validation`；URL、字节数和 SHA-256 固定在 `docs/public-validation-sources.json`。内容改变会停止核对，不静默换数据。原始厂商 PDF/ZIP、外部测量 CSV 不混入通用源码包；本地工程与结果在 `outputs/public-validation`。公开算例对标包带 MATLAB Friis 脚本，但尚待目标授权环境实际执行。

本地验证工程压缩包：`dist/RF-Link-Calculator-2.0.1-public-validation.zip`，包含 39 个可直接打开的工程、对比结果、MATLAB 交接包、归一化 IQ 拟合模型及来源清单。归一化模型用于复现实测预测验证，未经绝对功率标定不能绑定物理功率链路。

- Ruff 代码检查、Python 源码格式检查、前端脚本语法检查与依赖检查通过。保留的原始需求文档中的代码段未做格式改写。

- 浏览器实际选择公开 Friis 算例并比较 20 行，显示“公开算例吻合”；将对标对象改为扫频时，正确阻止混用链路参考。
- 浏览器实际打开 PGA-103+ 的 5 V、25°C 频率预算工程：1 GHz 下增益 16.27 dB、NF 0.75 dB、IIP3 25.45 dBm、输入 P1 6.64 dBm；完成 50 MHz～4 GHz 的 201 点扫频，无相位数据的列显示为空。
- 1280×720 与 1366×768 页面无整页溢出；浏览器错误日志为空。未添加说明段落，长版本说明保留于数据来源记录和导出材料。

## 仍需人工提供

- 实际目标器件型号、频带、偏置、温度和允许误差。当前 PGA-103+ 是公开基准，不能替代目标器件。
- 指定 MATLAB RF Toolbox、ADS、AWR 等合法运行环境，或完整条件与导出结果。本机命令和安装清单未发现可用环境；没有安装试用版或接受许可协议。
- 目标器件独立 AM/AM–AM/PM、双音、多功率/带宽/温度留出数据及 IQ 输入/输出绝对功率标定。P1 和 IP3 无法唯一确定完整非线性行为。
- 本版没有通用谐波平衡、IP2 导致的高阶互调和自动多通道噪声折叠。MathWorks 同一低中频算例的 HB NF 为 6.487 dB，本版 Friis 约 4.793 dB；这是模型范围差异，不能放宽容差掩盖，尚未对齐。
