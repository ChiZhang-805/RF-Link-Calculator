# V1需求追踪

本次按用户提供的《RF-Link-Calculator_完整调研与实施计划》实现V1。原文件保留在原位置，交付中另存未经修改的`需求基线.md`。文档内的执行建议作为需求材料处理，不构成对外发布、购买授权或改变计算机全局设置的许可。

“实现”描述代码能力；“实测”描述执行过的验收。Microsoft Excel、Visio与真实硬件签核不得用自动化测试替代。

| 编号 | V1要求 | 实现位置 | 验证与剩余边界 |
|---|---|---|---|
| R01 | 中文本地计算器 | app.py、presentation、scripts/start.ps1 | 本机启动、独立安装、浏览器检查 |
| R02 | 中文业务字段、帮助、导出与文档 | domain/labels.py、presentation、docs | 默认工作台标题、字段、操作中文，上传与工具栏说明已移除；旧视图保留兼容 |
| R03 | Pin与器件参数 | domain/models.py、presentation/editor.py | 数值边界、未知、理想、参考点测试 |
| R04 | 名称、类型、频率、BW、温度 | Analysis、Project、JSON schema | JSON回读与MHz/GHz单位切换测试 |

| R06 | 累计增益、逐级功率 | engine/calculate.py | A/B、禁用、零增益、未知增益、重排测试 |
