# 公式与模型说明

版本：schema 1.0.0，formula 1.0.0，compression p1_anchored_soft_saturation_v1。

所有功率为dBm，增益/NF为功率dB；线性功率比使用10而不是20的对数系数。内部不逐级舍入。T0固定290 K，k=1.380649e-23 J/K。

| 指标 | 定义 |
|---|---|
| 逐级输出 | Pin+前缀增益+本级增益 |
| Friis | Fsys=1+Σ(Fi−1)/A_before；NF=10log10(Fsys) |
| 匹配热无源 | F=1+(1/G−1)Tp/290，仅用于明确无源类型且G≤1 |
| 噪声温度 | Te=290(Fsys−1)，总输入噪声=kBn(Ts+Te)，输出噪声再乘总增益 |
| 输入IP3 | OIP3−G；系统倒数和=ΣA_before/IIP3_i，线性功率单位mW |
| 双音 | 总平均功率=每音功率+3.01029995664 dB |
| IM3 | 每个分量输出=3×每音输入+总增益−2×系统IIP3 |
| 有符号dBc | IM3输出−每音基波输出 |
| 实际输出P1 | IP1+小信号增益−1；线性外推输出P1=IP1+增益 |
| 灵敏度 | 输入参考噪声+所需SNR+实现损失 |
| 压缩动态范围 | 模型IP1−回退−灵敏度 |
| SFDR3 | 2/3×(IIP3−输入参考噪声)；该下限不是灵敏度 |
| 每音上限 | (输入参考噪声+2×IIP3)/3 |

单级压缩C(x)=10/p×log10(1+(10^(p/10)−1)×10^(p(x−IP1)/10))，输出=x+G−C(x)。p在1～10内，默认2。采用稳定softplus计算，不直接指数溢出。按真实估算输出传播到后级，再对系统总压缩=1 dB求根。Python使用夹根检查、最多8次区间扩张、80次二分、区间精度1e−8 dB。Excel使用保守初始界限、夹根验证与80次展开二分；未夹根时明确失败，不返回随意端点。

同p闭式为−10/p×log10Σ10^(p(G_before−IP1_i)/10)。它仅属于此模型族，用于不同实现交叉检查；不是所有硬件P1的通用规律。两个0 dB／IP1=0／p=2器件得到系统IP1=−1.505149978 dBm，不能取最弱阈值0 dBm。

噪声、IP3与P1的未知状态独立传播。理想器件是显式假设，JSON不写Infinity。源温度不替代NF参考温度。双音接近单音P1时停报可信IM3；缺P1时只给独立弱非线性外推并警告适用区无法核实。不把压缩增益重新代入Friis，不由IP3减常数推P1。

混频器支持和频与绝对差频，保存LO、SSB/DSB及兼容性确认；不自动加减3 dB转换NF。频谱翻转来自高侧LO；跨零频停止可靠频率／噪声预算。天线/ADC/DAC/数字边界只接受0 dB显式理想标注，不混用dBi/dBFS与电子链路增益。

测试覆盖A～F基准、随机100条同p链路闭式对照、不同p、多级／热平衡／源温度／双音口径不变量与异常状态。对数域支持极端累计增益；不可表示的等效温度标记计算失败，不输出NaN。

参考：[MathWorks rfbudget](https://www.mathworks.com/help/rf/ref/rfbudget.html)、[ADI级联互调与选择性](https://www.analog.com/en/resources/technical-articles/use-selectivity-to-improve-receiver-intercept-point.html)。具体软饱和参数化来自用户提供计划中的工程设计。
