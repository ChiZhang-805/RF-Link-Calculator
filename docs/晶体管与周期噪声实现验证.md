# 2.2.0 晶体管电路与周期噪声

## 本次完成

工作台“分析 → 电路”新增元件编辑、工作点、晶体管谐波平衡、周期噪声、噪声源贡献、稳定性检查、谐波/边带加倍验证、网表与对标工程导出。右侧每行只有标签和输入，整体固定视口，表格与参数区局部滚动。没有加入说明段落、格式限制或环境提示横幅。

电路与原有串行 RF 链路是两套显式输入：电路使用节点、电压源、阻容和晶体管；不把空链路的 0 dB 或标量 NF 当作电路结果。进入电路页隐藏链路条件和底部链路指标。电路模型完整存入 `lab.circuit`，进入计算散列；旧项目仍可打开。

## 确定模型范围

支持 R、C、接地理想电压源、NPN 本征 Ebers–Moll 晶体管，可有分支/反馈：最多 32 元件、4 晶体管、6 未知节点、12 总节点。电压源支持直流与最多 8 个同一基频整数倍的载波，幅度为峰值 V，相位按余弦定义。电路 HB 为 1～32 阶；加倍检查起始上限 16 阶。温度为 200～400 K。

晶体管的 IS、BF、BR 是**当前分析温度下**的参数，不包含从标称温度到工作温度的模型提取/缩放。CBE、CBC 是固定的线性电容，不是 SPICE 的非线性 CJE/CJC 或传输时间模型。

令 `IF = IS·expm1(VBE/VT)`，`IR = IS·expm1(VBC/VT)`，`VT = kT/q`。端子电流为：

```
IC = IF − (1 + 1/BR)·IR
IB = IF/BF + IR/BR
IE = −IC − IB
```

采用 SI 定义常数 `k=1.380649e−23 J/K`、`q=1.602176634e−19 C`。每个晶体管必须声明允许的电流、VBE 和结电压范围。结果越界、浮空节点、奇异矩阵、采样积分不收敛或牛顿迭代失败均报错。未知字段被拒绝，不悄悄忽略厂商模型参数。

此模型是晶体管级的有限实现；尚无 MOSFET、完整 Gummel–Poon/VBIC/HICUM、Early 效应、高注入、偏置相关电荷、传输延时、击穿、自热、电感、传输线或任意 SPICE/Verilog-A 网表导入。不能把几个 IS/β/电容参数当成真实 GHz 器件的完整模型。

## 数值方法

1. 先求节点直流 KCL；采用精确器件导数、阻尼牛顿法，收敛同时约束电流残差与按行导纳折算的电压残差。
2. 在真实电压 Fourier 坐标中求 `G·V + jωC·V + FFT(Idevice(V(t))) = 0`。已知电压源节点消元，未知节点联合求解。默认非线性积分采样为 `8×(2K+1)`，同一解再次用双倍采样核查积分残差。
3. “收敛”重新求 K 和 2K，并检查输出电阻两端的复数电压，包含新增谐波。阈值为 `max(1 nV, 交流最大 Fourier 系数×1e−4)`。数值残差收敛和谐波截断通过分别记录；不把二者混同。
4. 正频率 Fourier 系数 V 对输出电阻 R 的功率为 `2|V|²/R` W，直流为 `VDC²/R`。功率表中的 0 Hz 包含直流耗散；谱图显示交流且使用 120 dB 动态范围。

## 周期驱动噪声

求周期大信号解后，围绕该轨道线性化。噪声本身仍是小扰动。使用正、负频率边带的完整转换矩阵：

```
Y[m,n] = Fourier(Gdevice(t))[m−n]
         + δ[m,n]·(Glinear + j·2π·(foffset + m·f0)·C)
```

电阻采用单边 `4kT/R` 的 Norton 电流噪声。晶体管仅在**全周期正向放大区**使用独立 BE 与 CE 白散粒噪声源，单边密度分别 `2q·IF/BF`、`2q·IF`。当前实现要求每一采样点 `VBE≥5VT`、`VBC≤−5VT`；截止、反向和饱和区不输出这一噪声近似结果。外置基区/集电区/发射区电阻可作为普通 R 元件添加，其热噪声自然计入。

内部计算双边 PSD，源协方差为瞬时噪声强度的 Fourier Toeplitz 矩阵 `Q[m,n]=Fourier(S2(t))[m−n]`，保留非对角相关项。求 `Y⁻¹ Q Y⁻ᴴ` 后转换为正物理频率的单边、时间平均电压 PSD，分别返回每个独立噪声源的贡献。功率密度是该输出电阻上的 `Sv/R`，**不是默认 50 Ω 可用功率，也不计算未定义参考口径的 NF**。

计算前消去 RC 系统的代数约束，积分周期线性化方程求 Floquet 乘子。非稳定或临界解被拒绝；纯代数电路检查约束可逆。这里不支持自主振荡器相噪。

噪声“边带数”决定参与折叠的求解范围；“观测阶数”决定输出的 `|h·f0±foffset|`，两者分别设置。加倍检查固定观测频率，先验证 HB 截断，再将折叠边带 M 增至 2M；所有观测点噪声差须≤0.01 dB。也测试了观测点贴近求解边界时应失败的案例。

此版本只计算白噪声，不包含 1/f、载流子渡越相关、散粒源间高频相关、噪声自身的大幅非线性扰动、EVM 噪声积分或完整商用 PNoise/HBNoise 功能。

## 验证证据

完整回归 **127 项通过**；全新环境安装及全部算例烟测通过，界面在 1024×768、1280×720 和 1366×768 下检查。`tests/test_circuit.py` 包含 10 项测试：

- 独立一维根求解验证偏置，有限差分验证器件雅可比。
- 独立二节点微分方程 DOP853 积分与 HB 复数谐波对照（绝对容差 3e−10 V）。
- RC 热噪声 Lorentzian 与解析 Floquet 衰减率。
- 无载波 NPN 与独立 hybrid-π 噪声矩阵。
- 理想基极电压驱动的 Bessel 平均电流/散粒噪声恒等式。
- 有基极电阻反馈的周期噪声与逐时刻噪声增益积分对照（相对容差 2e−8）；冻结 DC 近似与之不同。
- 不支持字段、非法输入、越界、饱和噪声、浮空节点和不稳定交叉耦合晶体管电路被拒绝。
- 固定观测带宽的加倍验证通过，边界不足与低 HB 阶数失败。
- 项目往返、API、散列变化、物理单位容差、对标与网表导出。

此外**实际运行了 ngspice 41**：

| 对照 | 数量 | 结果 |

| 290/300/320 K × 0.66/0.70/0.74 V 偏置的 B、C 节点 | 18 | 最大差 11.20 µV，限值 20 µV |

共 32 项通过。保留了输入 `.cir`、原始 `.tsv`、运行文本、执行文件和数据的 SHA-256；详见 [外部对标记录](晶体管外部对标.json)。没有调整模型参数来抵消这些微小差值；例如 ngspice 输出的 IC/gm 对应热电压与本程序 SI 常数值略有不同，记录于 `constants.txt`。其余残差也包含瞬态积分/采样误差。

ngspice `.noise` 的外部结果仅核验**无载波**分支。周期驱动噪声使用前述独立解析/积分测试，不能宣称已与商用 HBNoise 对齐。验证工具也不是被测内核依赖，应用可在没有 ngspice 时正常计算。

```

```

外部参考运行使用 conda-forge 的 `ngspice-exe-41-h295a5eb_0.conda`，SHA-256 为 `ca2c615fe7a397d37fa7f54e02f80074e77a547e98d0b5421b6cb0aafbed135a`。下载地址与包来源另存 `晶体管验证工具来源.json`；运行时未作系统安装、不随应用分发。

项目入口为 `examples/circuits/NPN放大电路.json` 与 `RC热噪声.json`。同目录 `-电路.json` 为电路页专用导入文件。`samples/circuit-validation` 保存全部计算结果与对标包，`dist/RF-Link-Calculator-2.2.0-circuits.zip` 为便携验证包。`circuit.cir` 重建的是确定性电路；不会把普通 SPICE `.noise` 包装成周期噪声求解。

要验收目标器件精度，仍需选定器件、偏置和频带对应的合法厂商紧凑模型/实测标定，以及 ADS/AWR/SpectreRF 等目标环境的同条件结果。现有公开链路、S 参数、IQ 数据对照仍保留，但不能替代这些材料。模型精度和数值求解精度分别验收。
