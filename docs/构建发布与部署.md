# 2.3.0 构建、账户与部署

## 下载与安装

- [Windows 安装包和便携版](https://github.com/ChiZhang-805/RF-Link-Calculator/releases/latest)
- [公开入口](https://chizhang-805.github.io/RF-Link-Calculator/)
- Windows x64；安装包按当前 Windows 用户安装，无需安装 Python。便携版须完整解压后运行 `RF-Link.exe`，不能只复制单个 EXE。
- 桌面界面使用 Microsoft Edge WebView2 Runtime。Windows 11 通常已包含；缺少时从 [Microsoft 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装。程序没有捆绑整个浏览器。
- 当前安装包尚未使用付费代码签名证书签名；发布页附 SHA-256。可用 `Get-FileHash 文件路径 -Algorithm SHA256` 校验。

## 账户与数据

打开软件先注册或登录。桌面账户保存在本机 `%LOCALAPPDATA%\RF Link\accounts.sqlite3`；计算不需要联网。注册时显示一次恢复密钥，找回本机密码需要该密钥。云端账户通过邮箱验证注册，以邮件链接找回密码。桌面账户与各云端实例独立，当前没有跨端同步；项目可通过 JSON 导出、导入迁移。

密码使用 Argon2id；会话保存在 HttpOnly Cookie，云端启用 Secure；项目读写按账户 ID 校验。会话与恢复令牌在数据库中仅保留摘要，令牌一次使用，重置密码撤销旧会话。登录、注册、计算均有请求限额，账户最多保存 100 个项目、256 MiB。数据库未作静态加密，本机操作系统管理员及持有服务器数据盘权限的人仍可访问项目数据。

数据库使用 SQLite WAL，适用于当前单实例部署，不需要外接数据库。备份须使用 SQLite 在线备份接口，或停止服务后完整备份数据目录；不要在运行时只复制主数据库文件。恢复备份后也会恢复当时的账户和会话数据，需妥善保管。多副本、高并发和自动跨端同步应另行迁移到 PostgreSQL 等服务，并执行独立验收。

## 网页部署

GitHub Pages 是下载与文档入口，不能运行本项目的 Python 计算服务。正式网页版使用同一 Python 内核、FastAPI 账户服务和静态前端，部署在同一 HTTPS 域名下。此版本未配置任何第三方服务凭据，没有代购云资源。

已提供 `Dockerfile`、`render.yaml` 和 `.env.example`。可在 Render 的 **New → Blueprint** 连接本仓库。模板包含付费 Web Service 与持久化磁盘，创建前核对平台实际报价。也可以在自己的 Linux 服务器运行同一镜像，由反向代理提供 HTTPS。

需要由部署者填入：

| 变量 | 内容 |
|---|---|
| `RF_PUBLIC_URL` | 最终 HTTPS 站点根地址，不带末尾斜线 |
| `RF_SMTP_HOST` | 发信 SMTP 主机 |
| `RF_SMTP_PORT` | 587（STARTTLS）或 465（TLS） |
| `RF_SMTP_USER` / `RF_SMTP_PASSWORD` | 发信账户和专用密码 |
| `RF_MAIL_FROM` | 已获准发信的邮箱地址 |
| `RF_MODE` | `hosted` |
| `RF_LINK_DATA_DIR` | `/var/lib/rflink/accounts`，位于持久化磁盘内 |

缺少 HTTPS 地址和发信设置时，云模式拒绝启动。SMTP 密码只填写云平台的 secret/environment 界面，不提交到仓库。发信域名的 SPF/DKIM 配置由邮件服务商提供。公网反向代理必须保留原始 Host，仅信任平台代理传来的客户端地址，不能把未认证的旧开发服务器转发到公网。

容器启动时仅初始化数据目录权限，随后降为 UID/GID 10001 运行应用。计算在独立进程执行，120 秒超时终止，同时最多两项计算；大型波形、电路分析仍可能需要增加内存或缩减规模。持久化磁盘只支持单实例的本模板，勿直接增加副本。

部署验收顺序：健康检查 → 两个账户注册并收取验证邮件 → 各自保存同 ID 项目并确认隔离 → 修改和找回密码 → 标量、S 参数、波形和电路计算 → 工程包导出 → 重启后确认账户和项目仍在。真实 SMTP 投递、云端 HTTPS 和资源性能待开通服务后验收。

## 从源码运行

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-portal.txt
.\.venv\Scripts\python.exe -m pip install --no-deps -e .
.\.venv\Scripts\python.exe -m rf_link_calculator.portal
```

打开 `http://127.0.0.1:8510`；默认本机账户模式。若需要原生桌面窗口，再安装 `requirements-desktop.txt`，运行 `python desktop.py`。

## Windows 构建

Python 3.13 x64 与 Inno Setup 7.1.0 是本次实测组合。安装 Inno Setup 后运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\scripts\build_windows.ps1 -Iscc 'C:\Path\To\Inno Setup\ISCC.exe'
```

脚本收集第三方许可、运行回归、生成便携程序、执行冻结程序自检、构建安装包并输出 SHA-256。发布前还应安装到独立目录，检查安装后的 EXE、原生窗口、WebView2、文件下载和账户流程。代码签名需要所有者的证书或签名服务，当前未申请。

安装包包含计算代码、Python 运行库及 27 个内置示例。所需曲线、S 参数或 IQ 拟合参数可保存在项目 JSON 中。未随包分发商业器件库、厂商原始下载数据、商用求解器、ngspice 工具或用户项目。依赖许可随程序保存在 `_internal/THIRD-PARTY-NOTICES`；模型精度边界见 README 与验证文档，不能把安装成功等同于全面商用精度认证。
