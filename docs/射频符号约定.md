# 射频功能图符号约定

2026-09-23，符号版本 2.0。工作台、SVG 和可编辑 draw.io 共用 `diagram/symbols.py`，不在三个界面分别手绘。连接线表达射频功能块之间的信号方向；本软件仍是串行预算，不是引脚级电路仿真。

## 核对依据

- [MathWorks RF Budget Analyzer 官方文档](https://www.mathworks.com/help/rf/ref/rfbudgetanalyzer-app.html)及其中接收机截图：放大器为空心三角形，器件名称放在符号外，混频功能使用圆内交叉线。官方示例把 Amplifier 命名为 LNA1、LNA2；LNA 不需要另造一种外形。
- [draw.io 官方 abstract 符号库固定版本](https://github.com/jgraph/drawio/blob/7976c02e1b10b1687c028d82782f9f5d90a885d6/src/main/webapp/stencils/electrical/abstract.xml)：`Amplifier` 主体为宽高相等、向右的空心三角形，单输入/单输出；`Filter` 为直角方框、三条波形及上下阻带斜线；`Controlled Amplifier` 与 `Operational Amp` 是不同器件语义，不能混用。
- [draw.io 官方 radio 符号库](https://github.com/jgraph/drawio/blob/dev/src/main/webapp/stencils/electrical/radio.xml)：天线使用杆与分叉，不用带 ANTENNA 字样的箭头框。
- [IEC 60617 官方数据库](https://webstore.iec.ch/en/publication/2723)：正式电气图形符号的规范来源。完整条目需要订阅；本轮没有取得完整条目、具体符号编号和逐项规范性验证，因此不宣称本软件整套符号经 IEC 认证。

这里参考通用几何和端口约定，用本项目基础矢量重新实现；不嵌入 MATLAB 截图或复制商业软件图标。draw.io 源码为官方公开参考，具体版本以上方固定链接为准。

## 实施规则

| 类型 | 图形和端口 |
|---|---|
| 放大器 / LNA / PA / VGA | 同一空心三角形；名称和增益在外部。VGA 当前只预算给定增益，不添加未经建模的控制引脚 |
| 带通滤波器 | 直角框，三条波形，上、下波形加阻带斜线；参考 draw.io Filter |
| 低通 / 高通 / 带阻 | 沿用同一三频带表达，上至下约定高、中、低频；分别划去高+中、中+低、中频。该分类是本项目在通用 Filter 上的明确扩展，未宣称逐项 IEC 编号一致 |
| 混频器 | 圆内交叉线，左/右信号端口，顶部 LO；LO 支路连接到真实端口，不悬空 |
| LO | 圆内正弦波，底部输出连接混频器，页面与导出共用同一几何 |
| 衰减器 / 隔离器 | 直角功能框，分别用幅度缩减 / 单向箭头标记；不是内部电阻原理图 |
| 线缆 / 连接器 | 传输路径示意，不假设具体连接器型号、机械结构或引脚定义 |
| 耦合器 / 分路器 | 仅表示选定主路径；不增加可编辑但未参与计算的分支。真实多端口连接不在当前模型范围 |
| ADC / DAC / 数字边界 | 直角功能框，用 A/D、D/A、DSP 短标识；不表示已模拟转换器内部电路 |
| 自定义 | 空白功能框，以外部器件名称识别，不伪造未知器件的标准电路符号 |

所有符号使用深色线条、白色内部；青色仅标记外围选中区域，不改变符号本体。名字与参数不挤进器件内部。主路径端口固定为 `(0,50)` 和 `(240,50)`，混频 LO 为 `(120,0)`，LO 源输出为 `(120,80)`；SVG 与 draw.io 连接位置一致。draw.io 只建立实际使用的端口，端口不显示装饰圆点。

如交付单位指定 IEC、GB/T 或某个 EDA 符号库的精确版本及编号，应以其授权规范逐项验收；当前已有官方软件参照与可追溯映射，不能把“看起来相似”当成正式认证。
