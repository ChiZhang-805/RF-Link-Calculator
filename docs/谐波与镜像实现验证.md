# 2.1.0 谐波与自动镜像噪声

日期：2026-09-23。本版继续缩小 2.0.1 的模型缺口，新增实射频行为模型的谐波平衡与自动双边带噪声预算。尚未在本机执行 MATLAB RF Toolbox、ADS 或 AWR；本次结果不能称为目标器件或商用软件全面一致性验收。

## 已实现

- **分析 → 谐波**：直流、谐波、双音/多音互调，实数 LO 泵浦产生的和频/差频，反向传输与端口反射闭环，输出单极点频率响应。
- **器件 → 模型 → 实射频多项式**：导入系数与端口参数；模型随工程保存。此模型与同级其他模型互斥，避免重复使用增益。
- **谐波 → 收敛**：保留阶数加倍后重新求解，比较共有频带内距最大谱线 100 dB 以内的所有分量，并检查新频带中的显著分量；截断遗漏会判失败。
- **频谱 → 镜像噪声**：根据 LO 自动确定镜像频率，分别读取 RF 前级在信号/镜像处的增益与噪声；计算混频器内部及后级噪声，无需手填整链镜像增益。
- **分析 → 对标**：新增谐波及阶数加倍结果、自动镜像噪声的交接与参考比较；谐波输出包括有符号复波幅及相位。弱分量采用相对幅度容差，防止固定大绝对容差掩盖误差。

新增内容均为标签、数值、表格、按钮和结果。使用固定视口，未加入解释段落。示例菜单增加“谐波反馈链路”“谐波混频链路”“镜像噪声链路”。

## 谐波方程与数据

以 50 Ω 实参考阻抗的功率波建模，时域实波幅单位为 √mW。输入波 `a1(t)`、`a2(t)`；输出波满足：

```
b1(f) = S11 · a1(f) + S12 · a2(f)
b2(f) = S22 · a2(f) + H(f) · FFT[p(a1(t)) · pump(t)]
p(x) = c1·x + c2·x² + … + c9·x⁹
H(f) = 1 / (1 + j·f/fp)；fp=0 时 H=1
pump(t) = 1；混频器为 2·cos(2π·LO·t)
```

端口连接使用 `a = source + C·b`。常数线性项和频率响应进入每个频点的二端口矩阵，消去线性反馈后，用 Newton–Krylov 求解非线性傅里叶系数残差。非线性在补零时间网格上求值，网格覆盖整个多项式及 LO 乘积，再投影回保留的谐波范围；没有把前馈包络 FFT 改名为谐波平衡。

正频率傅里叶系数为 `Xk` 时，实波形使用正负共轭重建；非零频率的前向功率为 `2·|Xk|²` mW，直流为 `|X0|²` mW。最终结果乘负载接受功率因子 `1−ΓL²`；逐级路径是前向输出功率波，不是该节点的净吸收功率。源激励也计入 `1−ΓS²`。

CSV 格式为 `order,coefficient`，阶数从 1 连续到最高阶，缺少的中间阶填 0。导入时填写 `max_input`（实波幅峰值，√mW）、`pole_hz`、实数 `s11/s12/s22` 及来源。系数不是只凭 P1 自动猜出的完整器件模型；IP2/IP3 的幅度也不能确定非线性符号、相位或高阶行为。

在匹配、无输出极点的单级三阶多项式中，可以用解析式核对弱非线性截距：`IIP2_mW=c1²/(2·c2²)`，`IIP3_mW=2·c1/(3·|c3|)`。单音、双音及级联的所有实际分量仍由方程计算；两个二阶非线性级联也会产生三阶项。

**范围限制：**每个启用级都必须有独立谐波模型；1～8 级，1～16 个可公度载波，最高保留 1024 阶，1～9 次实多项式。源/负载及模型反射为实数宽带系数；不是任意晶体管网表、任意复数宽带大信号 S/X 参数、自治振荡器、任意分支电路或非公度多维频率网格。模型输入峰值超范围、栅格不符、线性反馈接近奇异或残差不收敛均拒绝给出成功结果。求得周期解不等于证明该解稳定。

谐波模型在首页小信号增益/扫频中使用其明确线性项；未提供的噪声与标量 IP3/P1 保持未知。主预算的输出标签仍为“线性输出”。非线性输出应在谐波页查看，不能用主预算卡片充当 HB 输出。

## 自动镜像噪声

本版适用一个差频下变频器、匹配源/负载及匹配器件端口，且输入声明 SSB NF。镜像频率 `fi=2·LO−fs`。源镜像噪温可单独设置；前级内部噪声使用该器件的模型与温度。

令混频器信号转换功率增益为 `Gs`，镜像转换增益为 `Gi`，SSB 噪声因子为 `Fssb`。其内部附加噪声谱密度为：

```
Ninternal = k·290·[Gs·(Fssb−1) − Gi]
Nout = Gs·Nsignal_input + Gi·Nimage_input + Ninternal
```

然后按后级增益和附加噪声继续传播。负的内部噪声意味着口径或模型矛盾，程序报错；不会强行凑出正值。相同双边带增益、无前级、两输入均 290 K 时，结果准确回到给定的 SSB NF，不重复加 3 dB。热无源镜像滤波器会自己产生热噪声，不能将其衰减量直接从输出噪声中扣除。

该功能是中心频率处的小信号双边带预算，按用户噪声带宽换算功率；不包含多个混频器的相关噪声矩阵、压缩工作点的导数噪声、LO 相位噪声、非线性高次泵浦噪声折叠或带内响应积分。不能直接将其与 MathWorks 示例的完整 HB NF 视为同一口径。

机器记录：`谐波与镜像验证.json`；生成脚本：`scripts/generate_harmonic_samples.py`。

| 二阶模型级联 | 三阶分量与展开后的多项式解析系数一致 |
| 含端口反馈 | 与每个时刻独立标量求根结果一致；线性特例与二端口终端换能增益一致 |
| 含反馈及动态极点 | 与独立 DOP853 时域微分方程积分、稳态 FFT 一致，选定复傅里叶系数误差小于 2×10⁻¹⁰ √mW |
| LO 混频 | 和频、差频的复幅值及输入相位正确保留 |
| 截断保护 | 16 阶遗漏的二次/三次谐波使加倍检查失败；扩至 32/64 阶通过 |

117 项自动化回归通过；Ruff 与前端语法检查通过。2.1.0 wheel 已在独立虚拟环境脱离源码运行验证，覆盖新模型和旧入口；安装路径与结果见 `独立安装验证.json`。原有 2736 项厂商数据核对、426 项网络计算交叉检查、40 行公开 MathWorks 参考与 OpenDPD 实测 IQ 验证重跑结果保持一致。

## 仍需要的外部条件

真实目标器件型号、工作频带/偏置/温度、绝对功率标定与允许误差尚未提供。商业软件运行环境或同条件的完整导出结果也仍缺少。现有公开 IQ 的复包络不能唯一恢复真实二次谐波与直流特性；本版显式多项式示例属于构造验证。对复杂器件仍需要更完整的大信号多端口模型、独立谐波/双音/噪声测量，才能决定后续模型阶数、噪声机制和验收指标。
