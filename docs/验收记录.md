## 桌面电子表格

**26个场景全部通过**，每个可用系统指标与独立Python实现的差值≤1e−5；全部工作表没有Excel错误类型单元格。先修改真实工作簿输入，执行CalculateFullRebuild，保存关闭，再由openpyxl读取已计算缓存对照，不把写入公式或静态快照当成重算。

实际产品为 **WPS表格12.1.0.29161**。COM自报Name为Microsoft Excel、Version为12.0、Build为29161.0，但实际进程为`et.exe`，路径记录于[桌面重算原始报告](桌面重算验证.json)。本机Microsoft Excel注册信息指向不存在的EXCEL.EXE，故**Microsoft Excel验收未完成**。未安装Visio。

场景包括：baseline、Pin、带宽、源温度、增益、NF、IP3、P1、缺NF、缺P1、禁用、不同p、整体重排、增加一级、清空器件整行、非法默认p、双音高功率、基准B/C/D/E/F、全部理想、全部禁用、混频噪声口径未知、200级。

检查中修复了缺P1时Excel非短路AND/OR求值造成的#VALUE错误；默认p补充1～10校验；额定筛查同时考虑独立双音总功率。“非法默认p”用例明确清空该级覆盖值，使它确实使用默认参数。最终报告位于开发机`artifacts/office-accepted`，包含本次独立生成和重算的26个工作簿。旧失败记录保留，未冒充通过结果。

随包提供一个[WPS实测工作簿](../samples/WPS实测-两级放大器.xlsx)。其他示例ZIP内的XLSX是新导出文件，尚未填充重算缓存；历史快照仍可查看。不能将实测一个文件的状态自动写到每份新导出的清单中。

## 性能与环境

Windows 11 build26200 x64，Python3.13.0，Intel Core i9-13900HX，物理内存34,086,969,344字节（约31.75GiB）。详细依赖见[性能与环境](性能与环境.json)和根目录第三方依赖说明。

200级链路、25次：首次51.39ms，热身后中位45.90ms，P95为52.08ms。确定性布局21.80ms；200级XLSX导出1.025秒。满足计划的计算P95<100ms、主要导出<10秒目标；这些是本机测量，不能作为其他机器的保证值。

本机缺少Graphviz dot，正常使用确定性宽图和分段布局；Graphviz故障降级经注入测试，真正dot布局未作本机成功路径视觉验收。基础导出不依赖它。未生成原生VSDX。
