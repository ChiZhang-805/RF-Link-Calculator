## 数据约定

- **频率曲线**：必需列 `frequency_hz,gain_db`；可选 `nf_db,phase_deg,iip3_dbm,ip1_dbm`。频率严格递增，按本级输入频率查表。dB 参数分段线性插值；相位先解缠再插值。未提供的列继续采用器件独立参数。
- **Touchstone**：`.s2p` 或二端口 `.ts`，S 参数，RI/MA/DB，实正参考阻抗。先将原始频点归一化至 50 Ω，再在复平面线性插值。接收规范噪声段；v1 的 Rn 乘参考阻抗，v2 的 Rn 已为 Ω；噪声频率单独校验。数据至少两点，不做频带外推。解析依赖 scikit-rf 2.1.0；不支持的端口/参数/阻抗情形拒绝导入。
- **功率曲线**：`pin_dbm,pout_dbm,phase_deg`。输入严格递增，输出单调不减。以最低测点的增益作为小信号增益；最低测点以下按该复增益线性延拓，最高测点以上拒绝推算。P1 仅在模型有效范围内有交点时返回。
- **IQ**：`i_in,q_in,i_out,q_out`。复包络单位 **√mW**，`mean(abs(I+jQ)^2)` 为平均 mW。采样率在波形条件中填写；不能把归一化 ADC 码值直接当作功率。拟合前可指定非负输出延迟；训练为前半段、验证为后半段，中间隔离至少 16 点。导入用于链路预测对比的 IQ 应先完成整体对齐。正则系数 0 表示普通最小二乘；秩不足拒绝拟合。
- **IMT**：`m,n,output_dbm`，同时提供 `rf_hz,lo_hz,rf_dbm,lo_dbm`。每行是 `abs(m*RF+n*LO)` 的绝对输出功率。驱动与当前级输入条件不一致时拒绝使用。不根据缺失资料猜测驱动缩放关系。
- **外部参考**：`scope,metric,value,unit,status`，配合工程包 `case.json` 的输入散列和分析参数。理想无有限值用空 value 与 `ideal`，不是填 0。单位或状态不一致、缺失行、过期输入都不能判为通过。外部来源由导入者声明，程序不冒充验证其真实性。

项目 schema 1.0.0 继续可读；添加模型后保存为 2.0.0，模型与数据嵌入项目文件，不依赖机器上的原路径。项目上限 32 MiB；单次模型文件 8 MiB，曲线/S 参数最多 8192 点，IQ 最多 32768 点。模板内的数字均为构造值；示例来源在项目和数据元信息中保存。

## 计算边界

1. **线性失配**：两端口 S 与噪声波协方差处理双向反射。有源 S 文件只有标量 NF 时不能确定噪声相关性，故 NF 返回未知；无源噪声根据 `kT(I−SSᴴ)`，且检查无源性。理想无噪声只在显式选择时生效。
2. **逐级结果**：失配网络逐级预算是截断前缀网络接指定终端的结果，不是完整双向网络内的功率探针。最终整链增益与 NF 使用整个级联网络。主结果中的噪声采用中心频点窄带预算；频谱页的“带内噪声”执行频率积分，二者不能混称。
3. **非线性**：AM/AM、AM/PM、记忆多项式与复包络 FFT 是行为模型。没有实现通用电路谐波平衡、任意反馈/分支、热记忆电路或晶体管物理模型。带反向耦合/失配的网络不能直接接单向非线性曲线求压缩；不兼容时明确留空/拒绝，而不是沿用旧标量结果。
4. **同级重复增益**：完整功率曲线与频率小信号模型同时挂在同级时，线性扫频仍可用，非线性求解拒绝；需要依据实际测量拆成独立线性网络和非线性级，或提供更完整的大信号端口模型。曲线不能唯一确定 IP3，界面中的 IP3/SFDR 仍来自独立输入；独立双音失真在频谱页求解。
5. **标量频谱回退**：IP3 模式使用明确的复三阶多项式（压缩相位约定）；峰值距离 IIP3 少于 10 dB 时拒绝。P1 模式使用原 P1 软饱和模型与零 AM/PM；它不保证与独立 IP3 同时吻合。线性模式显式忽略非线性。未声明参数不会自动变为理想。
6. **混频**：FFT 使用所选和/差频通道，高侧 LO 做复共轭。IMT 是单 RF+LO 的固定驱动测量表；不虚构多个 RF 载波之间的混频交叉项，也不接受已有多谱线进入第二张单载波 IMT 表。重合频率条目保留各来源，未知相位时不伪造相干合并。
7. **噪声积分与镜像**：带内积分按所选单调变频通道积分输出噪声谱密度，跨折叠点拒绝。镜像计算要求恰好一个混频器、已确认 SSB 口径和用户提供的**整链镜像传输增益**；将 SSB 已包含的 290 K 镜像项替换为实际镜像温度，不能重复加上 3 dB。未实现自动从多通道大信号混频模型提取镜像转换矩阵。
8. **收敛**：频谱支持 ×1/2/4/8 过采样；“收敛”实际将采样率加倍，比较基准结果中距最强谱线 100 dB 内的已检出分量。通过只适用于报告中比较的频带和分量，不代表全谐波平衡残差收敛。频率采样数和过采样倍率是两个独立参数。
9. **波形**：模型只在训练采样率与输入峰值范围内预测。波形 EVM 是时间样本在消除一个最优复增益后的 RMS 误差；不是已完成同步、均衡、符号解调的 3GPP/IEEE 制式 EVM。邻道指标使用 Hann 窗、功率归一化积分；主/邻道范围必须分离且位于 Nyquist 内。FFT 滤波按有限周期记录处理，需测量数据提供足够稳态区间。

## 导出与复现

标量项目继续导出原公式工作簿。高级项目导出包含模型、数据、结果和假设的**静态快照工作簿**，没有冒充可在 Excel 内重新求解 S 参数/FFT 的公式表。高级项目禁止用旧器件 CSV 丢弃模型；请保存项目文件或工程包。SVG/draw.io 标注采用实际计算的本级参数。

`examples/models` 含五套合成工程和数据；`samples/model-validation` 含计算与对标交接包。可离线执行：

```powershell
.\.venv\Scripts\python.exe scripts/rf_lab.py examples/models/扫频链路.json examples/models/sweep-request.json outputs/sweep.json
```

接口入口为 `lab-import / lab-sweep / lab-spectrum / lab-convergence / lab-noise / lab-image / lab-waveform / lab-fit / lab-handoff / lab-compare / lab-power`，复用本机来源校验，不访问外部服务。请求、结果和模型中均保留可复现的数据及输入散列。

## 仍需人工提供的材料

- 合法可用的目标商用软件环境，或从该环境导出的结果、软件/版本/求解器/所有模型设置。基础 MATLAB 脚本已生成，但本机尚未执行目标商用软件对标。
- 实际目标器件的频率、偏置、温度、阻抗条件与厂商模型/测量数据，包括 AM/AM–AM/PM、双音、完整噪声参数、混频表或已校准 IQ。
- 与训练集独立的功率/带宽/温度测量，以及允许误差的工程指标。当前合成留出验证证明数值实现，不证明实物预测准确。

真实 Microsoft Excel 和原生 Visio 验收仍沿用原交接条件。WPS 的旧标量验证结果不能用作高级模型或商用 RF 工具的精度验收。
