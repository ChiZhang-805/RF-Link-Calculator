# RF Link工作台布局方案

状态：已实现并进行实际浏览器验证。以2026-09-23用户反馈为准：一屏操作、少文字、图标化，通过切屏而不是整页下滑组织功能。应用1.1.0将此方案实现为默认工作台，复用原计算内核。

## 主工作台

目标1920×1080桌面显示器，实际适配的是扣除浏览器栏后的可用视口。以1440×800内容区域为设计基准，1366×768显示器下用更紧凑的布局和较少表格行。页面自身不出现横向或纵向滚动条。

| 区域 | 内容与交互 |
|---|---|
| 顶栏 | 小尺寸RF Link标识、项目下拉、链路/分析/框图导航、新建/打开/保存/撤销/重做图标、计算、导出、设置 |
| 条件栏 | 输入功率、工作频率、噪声带宽、源温度、单音/双音切换、条件按钮；单位直接附在输入框右侧 |
| 左侧上部 | 链路缩略画布；点击器件选中；图形使用滤波器、三角放大器、三端口混频器等真实区分 |
| 左侧下部 | 可直接编辑的器件表，添加/复制/删除/上移/下移；按可用高度分页，不出现内嵌长滚动列表 |
| 右侧 | 当前选中器件的检查器；参数/频率/来源三个页签；选中状态与画布、表格始终一致 |
| 底部 | 六项固定结果：总增益、NF、IIP3、输入P1、输出功率、SFDR；统一参考口径，单位紧随数值 |

左侧约72%、右侧约28%，检查器建议宽320～380px。输入框标准高32～36px，正文14～15px，结果数字24～28px；不使用占满首屏的大标题和大型说明卡片。画布、表格和检查器的外框对齐，青色只用于选中状态和主要动作。

## 切屏组织

- 链路：填条件、编辑器件、计算，并在底部看关键结果。这是默认入口。
- 分析：页面主体替换为分析视图，通过“总览 / 逐级 / 压缩 / 双音”切换。总览显示完整结果；逐级表分页；压缩与双音使用图表和必要控件。不会把所有分析长串堆在一页。
- 框图：主体变为大画布，提供缩放、适应画布、分段选择和导出。长链路通过分段、画布平移和缩放浏览，不拖长网页。
- 项目管理：顶栏项目下拉与新建/打开图标；名称等信息在对话框中编辑，取消常驻的宽项目管理侧栏。
- 更多分析条件：所需SNR、实现损失、信号带宽、压缩回退、默认p等由“条件”打开定高对话框。内容按“基础 / 双音 / 压缩”分组切换。
- 设置：数据目录、环境诊断等放在设置页签/对话框内，仅需要时打开。
- 导出：点击后选择工程包、工作簿、矢量图或可编辑框图。未提供的格式不出现；格式名称仅在选择文件类型时出现，不在主界面长篇介绍。

## 文字与图标

主屏删除常驻说明：构造示例声明、VSDX未启用、模型介绍、本地中文工具、匹配标量预算、文件大小和格式说明、保存路径、框架Deploy/Profile等。打开文件直接调出文件选择器，不显示拖拽上传区域或5MB提示块。

主屏保留的是标题、字段名、单位、当前数值、必要操作，以及当前动作产生的简短错误。科学模型和参考点仍保存在数据与导出报告中，参数的口径细节通过悬停/聚焦提示或点开详情读取，不占常驻空间。

| 图标即可 | 图标＋文字 | 保留文字的导航与字段 |
|---|---|---|
| 新建、打开、保存、复制、删除、上移、下移、撤销、重做、缩放、设置 | 添加、计算、导出、条件 | 链路、分析、框图，以及参数名、下拉值和单位 |

图标仍配中文tooltip、键盘焦点和无障碍名称；不靠用户猜图标。删除可撤销，已禁用的动作视觉弱化。颜色不单独承担状态含义。

## 一屏策略

页面用固定视口工作区，禁止用overflow:hidden简单裁掉内容。主屏垂直预算：顶栏约56px，条件栏约76px，结果栏约88px，其余分配给编辑工作区；高度减少时优先缩短链路缩略图和减少表格每页行数。

表格采用4/6/8行等页容量，上一页/下一页和页码固定可见。200级仍采用分页。窄窗口将右侧检查器转为覆盖抽屉或独立参数页，不把它堆到表格下面。高级字段通过页签或对话框展开，浮层也需按高度适配。

右侧检查器允许滚轮内部滚动，滚动条隐藏；每行左侧标题、右侧输入，主页面不跟随滚动。框图画布允许平移/缩放；页面本身不随滚轮无限延长。滚轮不应意外修改数值。低高度时保留主要操作与关键输入，不靠缩小到难读字号塞进一屏。

## 数据状态

编辑后，计算按钮显示待更新状态，底部结果不冒充当前输入的有效值。输入错误就地标记对应字段；点击错误标记定位问题。只在有实际问题时出现简短反馈，不预先展示环境或模型告知横幅。未知与理想保持数据层区分，单元格可以通过图标/短值和详情表达。

页面之间保留草稿、选中器件、页码和结果。画布与表格操作同一个稳定器件ID。参考点在检查器明确选择，例如IP3输入/输出，P1输入/实际输出/线性外推；简写表头不改变计算定义。

## 设计验收

1. 默认页面一屏出现条件、链路、器件表、所选器件参数与核心结果。
2. 1920×1080与1366×768显示器的浏览器内容区域均无整页滚动；125%缩放时采用紧凑/抽屉布局。
3. 使用200级项目时分页、分段和器件定位可用，页面不变成长列表。
4. 没有常驻说明横幅、技术介绍、文件格式提示或巨型标题。
5. 高频操作可发现，图标有悬停名称；计算/导出在所有工作屏有固定位置。
6. 更改输入后不能误导性呈现旧结果；必要参考点仍能通过控件和详情明确获取。
