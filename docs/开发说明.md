# 开发与维护

运行和安装命令见根目录README。`src`采用标准Python包，通过editable安装或wheel导入，不修改sys.path。Python内核仅依赖输入域模型，计算不读取UI状态、不调用Excel、不执行网络请求。

数据流为：编辑草稿 → schema与语义校验 → 输入快照 → calculate(Project) → ResultBundle → 结果展示/各格式导出。计算开始时复制输入，导出前再次校验project_hash。纯注释更改也使旧报告失效；calculation_hash忽略显示与来源信息，便于识别数值条件。JSON数字1和1.0具有相同散列语义。

`domain`含不可变dataclass、数值状态、schema适配、字段验证和中文名称；`engine`含独立数值模型；`application`管理链路结构；`persistence`负责JSON/CSV与原子保存；`diagram`生成共享场景；`exporters`单向输出；`presentation/server.py`提供仅回环HTTP接口，`presentation/web`提供原生HTML/CSS/JS工作台，旧Streamlit页面保留兼容。IP3和动态范围的公式较短，集中在calculate.py，不为目录外观拆成无职责的小文件。

每项Metric包含value、unit、status、reference、model、reason、assumptions和dependencies；Issue单独记录告警，具体字段以models.py为准。`None`不代表0；`ideal`不代表参数缺失。项目schema为1.0.0，公式与压缩模型分别版本化。改变参考点或公式必须升级公式版本，并解释基准变化。

## 回归命令

```powershell
.\.venv\Scripts\python.exe -m pytest -q --cov=rf_link_calculator.engine --cov-branch --cov-report=json:artifacts/coverage.json
.\.venv\Scripts\python.exe -m ruff check src scripts tests app.py
.\.venv\Scripts\python.exe -m ruff format --check src scripts tests app.py
.\.venv\Scripts\python.exe -m build --wheel --no-isolation
.\.venv\Scripts\python.exe scripts/verify_clean_install.py
.\.venv\Scripts\python.exe scripts/verify_excel_desktop.py --output artifacts/office-check
```

桌面脚本只打开自身生成的工作簿。COM名称并不能证明产品身份，必须查看actual_engine和executable。测试通过要求所有对照指标误差≤1e−5且全工作簿无公式错误；桌面检查不属于普通pytest，因为依赖本机软件。进程超时处理以本次记录的PID、可执行路径和创建时间共同识别，避免关闭用户进程。

`scripts/build_schema.py`同步根schema与包内schema；两份必须相同。`scripts/export_example.py --write-examples`刷新15个固定ID样例；全部为构造值，不作为厂商规格。`scripts/release_evidence.py`写实际依赖版本、许可证元信息和性能记录，不从requirements范围猜测实装版本。

## 维护边界

- JSON拒绝重复键、NaN/Infinity、额外字段、更高版本、重复ID、超长文本和超过200级；5MiB限额先于解析。
- 原子保存用同目录临时文件、fsync与replace；失败保留旧文件。自动备份只裁减本程序的旧备份。
- XML通过ElementTree转义，不直接拼用户字符串。SVG不嵌脚本或外部图片。
- 用户Excel字符串强制普通文本，CSV按规范转义潜在公式前缀。
- Graphviz使用固定内部节点ID、参数数组和超时，不经shell执行用户内容。缺失或故障自动采用确定性宽图与分段图。
- 每种导出单独记录成功或失败；单个格式失败不会伪造同名空文件。源码保留异常类型供定位。
- 工作台只监听127.0.0.1，校验Host和写请求Origin、限制请求大小；静态资源按白名单从包内读取。浏览器标签页持有草稿，服务端不保存全局项目状态。若自行改成网络服务，认证、多用户持久化和服务加固属于新增部署工作，不在本地版承诺内。
- draw.io/SVG文字修改不反向改变JSON。工作簿重算只影响当前工作簿，历史快照和网页输入保持原有语义。

## 工作台维护

`workbench.py`或`python -m rf_link_calculator.presentation.server --port 8501`启动；无需Node构建或CDN。浏览器仅调用同源 `/api`。前端保持待计算状态、50步撤销/重做、同标签页sessionStorage草稿；只有保存动作写磁盘。后端重新验证schema、计算并校验项目散列后才导出。

应用版本1.1.0表示本次界面发布，需求计划中V1.1的AM/AM等后续功能并未因此变为已实现。公式与schema仍为1.0.0。修改图形时同时检查共享symbol、SVG及draw.io端口；以[射频符号约定](射频符号约定.md)追溯参照，不宣称未经验证的标准认证。
