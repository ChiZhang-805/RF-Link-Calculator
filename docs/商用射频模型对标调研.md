# 商用射频模型对标调研与实施路线

调研日期：2026-09-23。对象：当前应用1.1.0、公式1.0.0。本文是后续研发建议，本轮未改动计算引擎，也未运行商业软件对标。先以现有串行接收/下变频链路为验收对象，功放调制信号分析单独扩展。

## 结论与目标

建议把“媲美”定义成可验收的范围：给定同一器件模型、工作条件、激励、参考平面及求解器设置，目标场景中的逐级与系统结果能复现；输入真实器件数据后，预测误差经过独立测量评估。界面接近、内部单元测试通过、输出小数位多，都不能代替这两项证据。

第一目标是把基础链路预算做到可与商用同类模式逐项核对；第二目标是频率相关器件、失配和实测非线性；第三目标才是混频杂散、波形和有记忆模型。完整ADS/SystemVue还包括更广的电路、系统和设计工作流，不能把一个链路预算工具的有限场景验收等同于全部替代。

## 官方资料确认的能力

| 对标对象 | 官方能力 | 对本项目的意义 |
|---|---|---|
| MathWorks RF Toolbox / RF Budget Analyzer | Friis与Harmonic Balance求解器；两者能力有差别，HB进一步处理IP2、非线性及噪声折叠 | 对标必须记录具体求解器，不能把两个模式的结果混成唯一标准答案。见[求解器比较](https://www.mathworks.com/help/rf/ug/determine-linear-and-nonlinear-characteristics-of-rf-chain.html) |
| MathWorks amplifier | 多项式、S参数和AM/AM–AM/PM模型；支持网络与噪声数据 | 增益、NF、IP3、P1几个标量不能描述所有模型。见[amplifier模型接口](https://www.mathworks.com/help/rf/ref/amplifier.html) |
| Keysight Spectrasys | 射频频谱域分析，跟踪谐波/互调的产生位置与传播路径，并考虑失配等效应 | 需要逐频谱分量的传播和来源追踪。见[官方技术说明](https://www.keysight.com/at/de/lib/resources/technical-specifications/spectrasys-rf-system-simulation-1823684.html) |
| MathWorks mixerIMT | 用IMT表描述单载波与LO的混频杂散 | 混频器应有转换/杂散数据，不能只把中心频率加减LO。IMT表本身也不能自动代替任意多音非线性模型。见[mixerIMT](https://www.mathworks.com/help/rf/ref/mixerimt.html) |
| MathWorks PA表征 | 利用输入/输出数据拟合无记忆和有记忆模型，并比较模型误差 | 宽带调制信号需单独验证记忆效应，不能从单音压缩验收直接推断EVM/邻道结果。见[PA表征示例](https://www.mathworks.com/help/simrf/ug/power-amplifier-characterization.html) |

资料说明：公开文档能确认功能与部分数学定义，不能据此宣称已复制商业闭源求解器。各软件版本、器件模型与默认值应在实际对标时固定。

## 本项目当前差距

以下结论来自实际检查 `domain/models.py`、`engine/calculate.py`、`noise.py`、`frequency.py`、`compression.py`。

| 项目 | 当前代码 | 需要补齐 |
|---|---|---|
| 器件数据 | 每级一个增益/NF/IP3/P1，工作频率和允许频率范围 | 随频率、温度、偏置、功率变化的数据与有效范围；数据来源、版本、测量条件 |
| 频率选择性 | 范围检查，越界告警；通带内仍为同一增益 | 插损/增益/相位曲线；分别作用于有用信号、干扰、谐波和互调；带内噪声积分 |
| 端口与失配 | 固定50Ω匹配，单向标量级联 | 复数S参数、端口阻抗、双向反射、换能/可用/工作功率增益的明确区分 |
| 噪声 | Friis与热无源模型；混频器靠人工确认噪声口径 | 频率相关NF；失配条件下的噪声参数/相关矩阵；镜像通道与噪声折叠 |
| IP3 / IM3 | 平坦通道、弱非线性、相干最坏相位；IP3与压缩独立 | 分量传播、滤波选择性、相位/相关性假设；适用范围外切换非线性模型 |
| 压缩 | P1锚定软饱和，p指定曲线形状；单音逐级求根 | 实测AM/AM–AM/PM表、模型选择、拟合残差；不能仅调p来宣称真实器件已校准 |
| 混频 | 选定和频或绝对差频、频谱翻转、跨零检查 | 转换增益/损耗、镜像、端口隔离、LO泄漏、IP2/IMT杂散、多个噪声来源 |
| 验证 | 65项自动化、闭式/数值交叉、WPS重算 | 商用工具固定版本的外部结果、原始模型文件、实测留出集、不确定度 |

特别值得优先做的是滤波选择性：滤波器对干扰频点的抑制会改变后级产生的互调。ADI给出了包含级间选择性的级联IP3推导。我们现在的平坦标量模型不能完整表达这个作用，见[ADI选择性与截点分析](https://www.analog.com/en/resources/technical-articles/use-selectivity-to-improve-receiver-intercept-point.html)。

## 推荐实施顺序

### 阶段A：先建立外部对标与数据规范

1. 固定目标软件版本、求解器、模型名称及开关。起点选MATLAB Friis模式与我们共同支持的匹配窄带条件；另外准备一套独立手算/解析结果。
2. 同一份案例描述生成本软件输入和目标工具脚本；导回机器可读的逐级结果。记录原始导出、日期、软件版本、模型/输入哈希与单位转换过程。
3. 优先核对增益、NF、噪声、输出功率、灵敏度、输入/输出IP3、弱非线性IM3、SFDR。P1只在模型相同后作同值验收，不用不同压缩模型强行比较。
4. 区分实测值、厂商典型值、保证上下限、拟合值和假设值；缺项保持未知，不能偷偷套入默认NF或相位。

交付：对标工具、固定案例、差异报告、模型能力清单。数学公式口径不一致时先定位定义，不能靠调整常数迎合某个截图。

### 阶段B：频率相关数据与线性网络

先加入增益/NF/IP3随频率表及扫描，再加入Touchstone、复数两端口级联和失配。每级按该级实际RF/IF频率取值，而不是把全链路都按输入RF频率查表。相位连续性、频率网格、单位及参考阻抗统一；默认拒绝数据覆盖范围外推。

Touchstone导入先明确支持的版本子集，未支持的关键字明确拒绝。IBIS的2.1规范区分网络和噪声数据；噪声电阻在旧、新格式的归一化规则有差异，噪声频点也不必与S参数频点相同。见[Touchstone官方规范](https://ibis.org/touchstone_ver2.1/touchstone_ver2_1.pdf)。

推荐评估scikit-rf作为线性网络基础库。它已有Touchstone读取、复数网络表示、参数转换和网络连接；采用前固定版本并用独立解析案例验收，不能拿同一个库的两个入口互相验证后就称独立对标。见[Network教程](https://scikit-rf.readthedocs.io/en/latest/tutorials/Networks.html)与[API](https://scikit-rf.readthedocs.io/en/latest/api/generated/skrf.network.Network.html)。

有源器件只有S参数时，仍不能确定完整噪声特性；任意源失配条件下，需Fmin、复数Γopt、Rn或等价噪声相关信息。只有50Ω下NF时，报告应限定该适用条件。无源热噪声可从满足物理条件的网络和温度构造，不能把这一特例泛化到有源器件。

交付：同一`.s2p`的网络结果、逐频增益/NF、带内噪声、失配结果的对照；在理想匹配极限必须退化回现有标量答案。匹配模型与S参数模型的器件连接处要防止重复计入增益/损耗。

### 阶段C：真实非线性器件行为

支持可切换的分析模型：当前P1锚定估算、明确数学定义的行为模型、实测AM/AM–AM/PM表。实测表至少包含输入功率、输出功率、相位变化，并附频率、温度、偏置、负载及参考平面。MATLAB的AM/AM–AM/PM表也采用输入功率/输出功率/相位变化三列形式，见[表接口](https://www.mathworks.com/help/rf/ref/computeampmtable.html)。

先验证单音曲线、单级及多级P1，再对双音作独立验收。若无记忆模型适用，可由同一个复数包络传输关系计算多音输出；采样率、过采样、FFT窗、频点对齐和功率归一化都要记录。单音表不能唯一描述记忆效应，无法据此保证所有双音间隔、调制带宽和大信号失配的预测。

在采用统一非线性模型的模式下，压缩与互调必须由同一模型产生；如果用户同时给的IP3与P1无法由该模型共同拟合，应报告残差或改换模型，不能静默丢弃其中一个参数。原来的独立IP3预算仍可保留为快速估算模式，并保持原有口径。

交付：幅相曲线、拟合与留出验证误差、P1/IP3/IM3共同对照、在弱激励下退化到预算结果。

### 阶段D：接收机频谱传播与混频

把单个中心频率升级为可追溯的谱分量：频率、复数幅度或功率、所属路径、相位/相关性假设、产生级与父分量。逐级滤波、非线性生成功率和频率变换，区分已有互调传播与本级新增互调，避免重复计算。

先支持限定阶数、限定音数的杂散分析和明确的IMT表缩放条件，再扩展更通用的模型。混频器需要镜像通道的滤波、终端温度和转换增益，才能计算对应的噪声折叠；SSB/DSB之间不能无条件加减3dB。

存在多条相干路径时要保留相位；缺相位时选择并标明最坏/非相干等假设，而不是伪造相位。对强非线性双向耦合、反馈或周期工作点，另设谐波平衡/电路包络求解工作包；不能将单向FFT传播命名为通用HB。

交付：滤波器位置对阻塞/互调的影响、各杂散来源、镜像噪声、级间传播，与同样模型设置的目标软件逐项对照。

### 阶段E：按真实需求扩展调制波形

若要预测发射机EVM、邻道功率、宽带PA，则加入输入/输出IQ数据拟合、记忆多项式或交叉项模型、带宽及功率留出验证。若工作范围只是窄带链路预算，此阶段可后置。不能把一个频点、一个功率下的单音拟合当成宽带调制验收。

## 验收怎么做

验证分三层，报告分别列示：

| 层次 | 比较对象 | 通过所证明的范围 |
|---|---|---|
| 数学实现 | 独立解析解、极限条件、不变量 | 方程、单位和数值求解实现正确 |
| 跨软件复现 | 相同输入、相同模型、相同求解设置的商业/独立工具输出 | 在所列模型和场景内结果一致 |
| 真实预测 | 未用于拟合的器件/链路测量，覆盖频率、功率、温度和偏置 | 在该测量覆盖域和误差预算内可预测硬件 |

建议的初始**软件验收门槛**如下；这是项目建议，不是商用厂商保证或行业统一规定：

- 解析标量内部对照：绝对误差≤1e−6 dB；对商用完整精度导出，初始目标≤0.001 dB，并记录参考文件的舍入精度。
- 复数线性S参数：在明确的良态案例中，逐元素绝对误差≤1e−6；零点附近不比较失去意义的相位。插值、去嵌与参考阻抗必须相同。
- 相同AM/AM表和插值定义：有效数据域内功率/P1初始目标≤0.01 dB；与硬件曲线的误差另报。
- HB、FFT或其他离散非线性解：先做谐波阶数、时间步/过采样、收敛残差试验；再按量和噪声底设置容差。未收敛、夹根失败、无数据覆盖均不得标为通过。
- 实测验收：先制定测量校准、去嵌、仪器与重复性误差预算和用途允许偏差，再约定合格界限；本轮没有真实测量数据，不能承诺统一的0.1dB或某个百分比。

相同测量序列用于拟合和验证会高估准确度；验证集应包含独立频点、功率、温度或波形。保留单项失败、最大误差与覆盖范围，不只报平均值。建议案例清单见[对标验收用例.csv](对标验收用例.csv)，全部是待实施计划，不是已通过记录。

## 数据和外部条件

起步可选一条实际链路：滤波器—LNA—混频器—IF滤波器—IF放大器；器件选择以可获得成套模型数据为先。建议先整理少量可验证器件，避免填充大量来源不明的标量库。

| 数据 | 最小字段 | 获取途径 |
|---|---|---|
| 线性响应 | 全复数S参数、频率、端口次序、Z0、温度/偏置、参考平面 | 厂商模型或校准后的VNA测量 |
| 噪声 | NF(f)及匹配条件；需要失配时补噪声参数 | 厂商数据、噪声测量；S参数文件不必自带噪声 |
| 非线性 | Pin/Pout/相位，频率、偏置、温度；独立双音测试 | 厂商功率扫描或台架测量 |
| 混频 | RF/IF/LO工作范围、LO驱动、转换与隔离、噪声口径、IMT | 厂商杂散表和测试数据 |
| 宽带PA | 对齐的输入/输出IQ、采样率、带宽、功率、校准信息 | 矢量信号源/分析仪或其他经过验证的测量系统 |
| 外部参考 | 目标软件版本、模型、设置、原始导出及脚本 | 可使用的MATLAB/Keysight环境，或有该环境者提供的可复现结果 |

有了模型文件，我们可以推进解析、数据导入、求解、自动对照与报告；商业运行环境和真实测量应由具备相应软件/设备的一方提供。未经访问不声称机器上已经有某个许可证，也不把公开示例截图当作完整外部验收。

## 对现有软件的改造位置

以下是建议的新结构，尚未创建实现：

- `domain`：在新schema中加入模型类型、数据文件哈希、条件坐标、端口和适用范围。为旧项目提供明确迁移，保留现有计算模式。
- `models` / `data`：频率表、Touchstone、噪声、AM/AM–AM/PM、IMT的导入、校验和版本记录。
- `engine`：保留现有标量求解器，增加线性网络、行为非线性、混频频谱的独立求解路径；结果包含实际使用的模型、数据覆盖和求解状态。
- `validation`：外部参考适配、对照报告、曲线误差、收敛扫描、数据留出验证。不要让同一实现既充当被测对象又充当唯一标准答案。
- `presentation`：右侧增加“模型/数据”入口，频率扫描与谱图放在分析切屏；保留现有单屏和少说明文字的交互原则。
- `exporters`：只有确实实现的模型才标记Excel可重算。高级网络/HB结果可先导出快照、原始数据、设置与可复现脚本；不能用旧标量公式冒充高级模型的Excel重算。

优先投入顺序：A外部对标与数据规范 → B频率/线性网络 → C实测非线性 → D混频频谱 → E按需波形。A、B、C每一段都能独立交付与验收；D/E涉及新的求解能力，不能用增加几个字段作为完成标志。
