# Excel使用说明

工作簿有使用说明、输入配置、器件参数、逐级计算、系统汇总、压缩求解、结果快照、公式与来源八张表。

蓝色输入区可以修改，灰色区是真实公式。器件表第4～203行预分配200级，未使用行禁用并隐藏；取消隐藏后填写并启用可添加器件。删除请禁用，不物理删除公式行。顺序依据整行位置，不依据“顺序”列数值；重排必须包含A～Y整行。公式表会按新位置传播。

IP3与P1使用明确模式和参考点。先选finite再填值；留空会使相关指标未知。ideal是用户明确选择的假设，unknown不会自动填成0。actual_output的P1换算含额外1 dB，linear_output不含。

压缩求解表没有宏或循环引用，200级×82行传播包括两次区间检查和80次二分；同p时另有闭式校验。默认隐藏空白器件输入行，不删除迭代公式。全部理想返回无有限P1，缺参数返回未知。

openpyxl只写公式、不负责计算。工作簿请求自动完整重算；不能计算公式的预览器可查看“结果快照”。快照不随输入变化，导出时间、版本和散列显示其历史含义。公式与快照不一致时先检查是否重新计算。

本次已用WPS表格12.1.0.29161实际重算26个场景并与Python比较，误差要求≤1e−5 dB，未见公式错误。Microsoft Excel未验证；不能因为COM接口叫Excel.Application就认为运行的确实是Microsoft Excel。验证脚本记录实际可执行程序路径。

输出中用户文本强制写为普通字符串，防止名称以=、+、-、@开头时成为公式。参数数量、公式边界与工作表结构是固定契约；不支持任意宏／外链／其他XLSX模板回读。极端数值超出Excel线性因子范围时会显示数值域状态，请在Python预算和测试过的工程范围内处理。

参考：[openpyxl公式边界](https://openpyxl.readthedocs.io/en/stable/simple_formulae.html)。
