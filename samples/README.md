# 示例交付包

本目录包含接收链路、下变频链路和200级长链路的工程ZIP。每个包有规范输入JSON、结果JSON、带公式Excel、SVG、原生draw.io、Visio说明和逐文件SHA-256清单。ZIP命名含UTC时间，避免覆盖旧结果。

全部参数为构造值。Excel新导出文件尚未重算缓存，静态结果可在“结果快照”查看；实际重算验证的独立工作簿位于开发机artifacts/office-accepted，不与新导出的样例混淆。

200级draw.io有20页，每页10级；同时有整链宽SVG与20张分段SVG。图中文字与JSON/计算结果之间是单向导出关系。

2026-09-23T10开头时间戳的接收、下变频和200级工程包使用符号2.0；此前样例保留为历史结果。新版为黑白功能符号、外部名称，与默认工作台一致。
